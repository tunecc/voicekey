# 设计：菜单栏图标品牌化重设计

## 现状

- 主线为 Rust + Tauri。菜单栏图标由 `app/src-tauri/src/ui.rs` 用 `include_bytes!` 嵌入 `tray.png` / `tray-active.png`，通过 `TrayIconBuilder.icon_as_template(true)` 作为模板图标显示；`set_tray_active` 在录音开始/结束时切换。
- Tauri 使用的 `tray-icon` 会把图标按高度缩放到 **18pt**，宽度按比例计算。现有资产为 44×44 PNG，等价于约 2.4× 像素密度。
- App 图标（`app/src-tauri/icons/icon.png`）的识别元素：深色圆角底板 + 三层正弦声波，颜色从青 → 蓝 → 紫 → 粉。

## 方案

用 AppKit（Swift）脚本绘制单色 alpha 模板图标，沿用 44×44 画布和现有 `icon_as_template(true)` 加载路径，只替换资产，不改加载逻辑。

- 模板图标只能表达单色与透明度，因此品牌识别依靠**单线声波造型**，不依赖颜色。
- 保持 18pt 下的可读性：笔画不小于 2.3pt，振幅在空闲/录音两态间有明显差异。
- 空闲 / 录音两种状态通过波形的振幅、线宽与不透明度区分。
- 画布尽量贴合墨迹，避免菜单栏出现额外留白；宽度不超过现有图标的合理范围。

## 候选构图

初版 A/B/C（竖条、底板、药丸）经预览后，用户明确希望菜单栏直接呈现 App 图标的“一条声波线上下浮动”。据此改为 E/F/G 三版单线波形，均渲染空闲 / 录音两态，并输出 18pt 实际大小在浅色、深色菜单栏上的预览。

| 候选 | 构图 | 取舍 |
| --- | --- | --- |
| E | 单线波形，一个完整 S 形 | 18pt 下最干净；波形细节比 App 图标少 |
| F | 单线波形，复刻 App 图标主声波的 1.5 个周期 | 保留小起势、深谷、高峰，最贴近主图标；仍是一条连续线 |
| G | 实心底板 + 镂空波形 | 品牌感最强；菜单栏中视觉重量最大 |

## 最终选定

用户选择 **F（App 原形）**。波形采用 1.5 个周期、相位 0.6 的单线，空闲态振幅 3.6pt / 线宽 2.4pt / alpha 0.85，录音态振幅 5.2pt / 线宽 2.75pt / alpha 1.0；图标整体仍为 44×44 模板 PNG。

## 生成与验证

- `Scripts/tray-icons.swift` 幂等生成：默认写入两个正式资产；候选预览模式输出到临时/预览目录。
- 校验：PNG 尺寸与 alpha 通道、模板下无彩色像素、两态差异可见；构建 `voicekey` crate 确认 `include_bytes!` 正常。
- 不改动 `ui.rs`、菜单结构、状态机与 Swift legacy 实现。
