# Spec Delta

## MODIFIED Requirements

### Requirement: 提示音设置

音频设置页必须提供提示音设置组：音效方案选择控件（简洁、自定义两选一，默认自定义），以及提示音总开关（默认开启）。自定义方案下必须提供录音开始、处理、完成、失败四个事件各自独立的音效选择控件，每个控件必须在「无」与内置音效集合之间选择，「无」表示该事件不发声；简洁方案下必须以只读方式展示固定音效映射：「录音开始」与「识别处理」两行发声（「识别处理」行的描述必须体现其播放时机为识别结果就绪、系统输出音量恢复后），「识别完成」与「识别失败」必须分行展示并各自明确标注不发声，且不得提供逐事件音效选择控件。音效方案、总开关与逐事件选择（含「无」）的任一设置变更必须即时生效并持久化。

#### Scenario: 关闭总开关后全静音

- **WHEN** 提示音总开关处于关闭状态
- **THEN** 无论音效方案为何，四个事件均不播放提示音，其余功能行为不变

#### Scenario: 方案切换即时生效

- **WHEN** 用户在简洁与自定义之间切换音效方案
- **THEN** 后续会话事件立即按新方案的规则发声，无需重启应用

#### Scenario: 简洁方案隐藏逐事件选择

- **WHEN** 音效方案为简洁
- **THEN** 设置页只读展示「录音开始」「识别处理」两行的固定音效映射，「识别处理」行描述体现「识别结果就绪、系统输出音量恢复后播放」；「识别完成」与「识别失败」分行展示并各自标注不发声；不展示逐事件音效选择控件

#### Scenario: 自定义方案恢复逐事件选择

- **WHEN** 音效方案切回自定义
- **THEN** 四个事件的音效选择控件恢复显示，且各事件保持此前已保存的选择（含「无」）

#### Scenario: 逐事件选择独立生效

- **WHEN** 音效方案为自定义，用户为某一个事件选择不同的音效或「无」
- **THEN** 该事件按新选择发声或不发声，其余事件保持各自原有音效

#### Scenario: 逐事件「无」持久化

- **WHEN** 用户为某个事件选择「无」后重启应用
- **THEN** 该事件的选择仍为「无」（该事件不发声），不得回退成默认音效，其余事件的选择与重启前一致

#### Scenario: 设置持久化

- **WHEN** 用户修改音效方案、总开关或逐事件音效选择后重启应用
- **THEN** 音效方案、总开关状态与各事件的音效选择（含「无」）与重启前一致

#### Scenario: 缺省字段兜底

- **WHEN** 现有配置文件缺少音效方案或提示音相关字段
- **THEN** 音效方案按默认值（自定义）生效，总开关按默认值（开启）生效，各事件使用默认音效，不产生错误
