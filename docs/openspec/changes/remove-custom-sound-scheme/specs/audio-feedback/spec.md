# Spec Delta

## MODIFIED Requirements

### Requirement: 会话事件提示音

应用必须在录音会话的关键事件（录音开始、识别结果就绪、识别失败（含转写超时与出错））按简洁方案固定映射与总开关发出提示音：「处理」事件的提示音必须（MUST）在识别结果就绪、系统输出音量恢复后播放，随后同批播放「完成」事件提示音（「完成」事件固定不发声，故实际只有「处理」一声）；录音结束、进入识别处理状态时不播放任何提示音；识别失败时不播放「处理」提示音，仅播放「失败」提示音。固定映射：开始=轻叮、结果就绪=轻啵、失败=警示（失败在 macOS 播系统错误音 Basso，Windows 播内置「警示」兜底）；「完成」固定不发声（识别很快，完成不另发音效）。取消录音时不得播放任何提示音。提示音的等待与播放必须（MUST）异步执行，不得阻塞或延迟识别与结果注入。

#### Scenario: 录音开始发声

- **WHEN** 用户通过热键或托盘触发一次正式录音开始
- **THEN** 播放「录音开始」事件固定映射的提示音（轻叮）

#### Scenario: 进入识别处理发声

- **WHEN** 录音结束、应用进入识别处理状态（结果尚未就绪）
- **THEN** 不播放任何提示音；「处理」事件提示音改于识别结果就绪、系统输出音量恢复后播放

#### Scenario: 处理完成发声

- **WHEN** 识别结果就绪（单候选直接注入，或多候选面板呈现）且系统输出音量已恢复
- **THEN** 先播放「处理」事件固定映射的提示音（轻啵，即完成信号），随后同批不再播放其他提示音（「完成」固定不发声）

#### Scenario: 识别失败发声

- **WHEN** 识别失败、出错或转写超时
- **THEN** 仅播放「失败」事件固定映射的提示音（macOS 播系统音 Basso，Windows 播内置「警示」），不播放「处理」事件提示音；录音刚结束时须等系统输出音量恢复后再播

#### Scenario: 简洁方案开始与处理按固定映射发声

- **WHEN** 录音开始、识别结果就绪或识别失败（音效方案恒为简洁固定映射）
- **THEN** 录音开始播轻巧"叮"声、结果就绪时播轻弹"啵"声；识别失败播系统错误音 Basso（macOS）；Windows 及系统音不可用时播内置近似音兜底

#### Scenario: 简洁方案完成与失败不发声

- **WHEN** 识别完成
- **THEN** 不播放「完成」事件提示音（识别很快，完成信号由结果就绪时的「处理」提示音承担）

#### Scenario: 自定义方案逐事件发声

- **WHEN** 读取历史 settings.json 中曾存在的自定义方案或逐事件音效配置
- **THEN** 自定义方案已移除，一律按简洁固定映射发声，逐事件字段被忽略且不影响启动

#### Scenario: 取消录音不发声

- **WHEN** 用户在识别完成前取消录音会话
- **THEN** 不播放任何提示音

### Requirement: 提示音设置

音频设置页必须提供提示音设置组：提示音总开关（默认开启）与简洁方案固定映射的只读展示行（「录音开始」「识别处理」「识别失败」三行发声：处理行描述体现「识别完成时轻啵一声」，失败行展示「警示」映射与试听；「识别完成」行标注不发声并说明「识别很快，完成不另发音效」）。必须（MUST）不提供音效方案选择控件，也必须（MUST）不提供逐事件音效选择控件。总开关的设置变更必须即时生效并持久化。

#### Scenario: 关闭总开关后全静音

- **WHEN** 提示音总开关处于关闭状态
- **THEN** 所有事件均不播放提示音，其余功能行为不变

#### Scenario: 方案切换即时生效

- **WHEN** 读取历史配置中的音效方案字段
- **THEN** 音效方案选择已移除，设置页不再展示该控件，应用恒按简洁固定映射发声

#### Scenario: 简洁方案隐藏逐事件选择

- **WHEN** 查看提示音设置组
- **THEN** 只读展示「录音开始」「识别处理」「识别失败」三行固定映射（「识别处理」行描述为「识别完成时轻啵一声」；「识别失败」行展示「警示」与试听），「识别完成」行标注不发声并说明「识别很快，完成不另发音效」；不展示逐事件音效选择控件

#### Scenario: 自定义方案恢复逐事件选择

- **WHEN** 查看历史版本中曾存在的逐事件音效选择控件
- **THEN** 该控件已随自定义方案一并移除，设置页不再出现

#### Scenario: 逐事件选择独立生效

- **WHEN** 读取历史配置中的逐事件音效选择
- **THEN** 逐事件选择已移除，这些字段被忽略，发声恒按简洁固定映射

#### Scenario: 逐事件「无」持久化

- **WHEN** 历史配置中某事件的音效选择为「无」
- **THEN** 该历史字段被忽略，不产生错误，发声恒按简洁固定映射

#### Scenario: 设置持久化

- **WHEN** 用户修改提示音总开关后重启应用
- **THEN** 总开关状态与重启前一致

#### Scenario: 缺省字段兜底

- **WHEN** 现有配置文件缺少提示音相关字段
- **THEN** 总开关按默认值（开启）生效，发声恒按简洁固定映射，不产生错误

### Requirement: 内置音效与跨平台一致

内置开源授权（允许再分发）音效集合必须作为简洁方案在 Windows 与系统音不可用时的兜底音源，不得依赖操作系统音效目录，macOS 与 Windows 的兜底音集合一致；简洁方案在 macOS 直接使用系统提示音 Tink/Pop/Basso（运行时引用、不随应用分发），Windows 使用内置近似音兜底，两平台发声语义一致（开始、结果就绪与失败发声，完成不发声）。

#### Scenario: 无系统音效目录依赖

- **WHEN** 在任一受支持平台（macOS 或 Windows）上触发系统音不可用的兜底路径
- **THEN** 兜底音来自应用内置集合，且两平台的兜底音集合一致

#### Scenario: 简洁方案平台差异兜底

- **WHEN** 简洁方案在 Windows 上触发录音开始、识别结果就绪或识别失败
- **THEN** 使用内置近似音发声，发声事件与 macOS 一致（完成同样不发声）
